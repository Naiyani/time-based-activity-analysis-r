# Time-Based Activity Pattern Analysis Using R

### Statistical Analysis & Data Visualization Work Sample

## Overview

This project analyzes Fitbit activity and sleep data to identify patterns in daily activity levels and determine time periods when individuals are awake but relatively inactive.

The analysis combines exploratory data analysis, visualization, and statistical testing to examine whether activity levels differ across time intervals and translate those findings into a practical research question.

## Research Question

**What times of day are people awake but relatively inactive?**

The analysis explores whether early morning and nighttime periods show lower activity levels while individuals are still awake.

## Tools & Methods

* R / RStudio
* Exploratory Data Analysis (EDA)
* Correlation analysis
* Data visualization
* Feature analysis and normalization
* ANOVA
* Kruskal-Wallis test
* Tukey post-hoc testing

## Analytical Workflow

**Data Exploration → Correlation Analysis → Feature Selection → Visualization → Statistical Testing → Interpretation**

The analysis combines visual exploration with statistical testing to evaluate patterns in the data and determine whether observed differences across time intervals are statistically supported.

## My Work

My work focused primarily on exploratory data analysis and statistical analysis, including:

* Examining relationships among activity and sleep variables through correlation analysis.
* Creating and interpreting boxplots, bar charts, histograms, and QQ plots.
* Analyzing activity patterns across time intervals using the project's opportunity score.
* Conducting ANOVA and Kruskal-Wallis tests to evaluate differences across time intervals.
* Using Tukey post-hoc testing to identify statistically significant differences between specific intervals.
* Interpreting statistical results and connecting the findings to the project's conclusions and limitations.

## Why This Project

This project is a strong example of how I use R to move from exploratory analysis to statistical testing and interpretation. I particularly enjoyed working through the analysis to determine which patterns were supported by the data rather than relying only on visual observations.

## Key Findings

The analysis identified differences in activity patterns across time intervals and provided statistical evidence for evaluating periods of relatively low activity.

These findings supported the project's broader objective of identifying potential time windows for marketing applications.

## Limitations

The opportunity score depends on the normalization and weighting choices used in the analysis. Fitbit activity data also does not capture factors such as geographic location, occupation, individual routines, or actual media consumption, which could influence activity patterns.
